Keyward Vault

Deploy the Digital Vault to your own Windows server — the same way you'd stand up a real PAM vault.

⬇ Download Vault Installer
KeywardVault-Setup.zip · ~50 KB · Windows 10/11 & Server 2016+ · installs a real Windows service

What's inside

🧩 Setup.exe

A guided wizard: license, install & safes folders, standalone or cluster mode, operator keys, master & administrator passwords — then it installs and starts the Vault.

🗄️ Keyward Vault service

A real Windows service that loads your keys, validates the license, opens its listener, and runs like a Digital Vault.

🖥️ Server Central Administration

The console to start/stop the Vault and watch its live log — encryption, firewall, cache, "server is up".

🔑 Easy licensing

No license server, no chasing files. The wizard generates a valid Keyward license for you in one click.

Install it on your VM

  1. Copy the folder to your Vault VM. Download the zip, move it to your VMware/Hyper-V/cloud Windows box, and extract it. (Works the same on an AWS/Azure Windows instance.)
  2. Run Setup.exe as administrator. Right-click → Run as administrator. If SmartScreen appears, click More info → Run anyway — it's unsigned because it's your own lab build.
  3. Walk the wizard. Accept the defaults for a standalone lab, choose Generate a Keyward license automatically, and set a Master and Administrator password at the end.
  4. Watch it run. Open Keyward Server Central Administration from the Start menu (or the install folder) and start the Vault — you'll see the live log, just like a production vault console.
Domain controller / cluster

Standalone is the right choice for testing. Choose Cluster-node and enter a peer address to model high availability. The Vault runs fine joined to your lab domain — install it on the member server you've prepared as the Vault host, not on the DC itself.

Command line (optional)

From an elevated Command Prompt in the extracted folder:

REM Silent install (standalone lab)
Setup.exe --silent name="Hasan" company="Keyward Lab" master="Str0ng!Pass" admin="Str0ng!Pass"

REM Uninstall (keeps your safes and keys)
Setup.exe --uninstall
